Toilet cleanliness map — automatically scores toilet cleanliness from Google Maps reviews and displays on an interactive map.

🌐 [日本語](README.ja.md) | [English](README.md) | [한국어](README.ko.md) | [中文](README.zh.md)

## Quick Start

```bash
git clone https://github.com/kaenozu/toilet-map.git
cd toilet-map
pip install -r requirements.txt
streamlit run app.py
```

## Features

- **Interactive Map** with color-coded toilet markers
- **Fuzzy Search** (Japanese, English, romaji)
- **Dark Mode** with auto tile switching
- **Multi-language** (JA/EN/KO/ZH)
- **Data Export** (CSV, GeoJSON, KML, GPX)
- **PWA** with offline cache
- **Accessibility** (keyboard nav, ARIA, a11y audited)
